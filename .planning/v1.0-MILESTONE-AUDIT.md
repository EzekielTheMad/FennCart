## Partial Requirements Detail

### SRCH-05: Review mode toggle
The toggle button renders in the review screen UI and the `AppConfig.review_mode` field is saved by the settings hub. However, the shopping router hardcodes `mode: 'exceptions'` as the Alpine initial state and never reads the user's saved preference. The toggle works within a session but resets on every page load.

### CART-03: Session cart view
`CartSession` and `CartItem` models exist and are correctly populated on every cart add. The data accumulates in the database. However, the `/history` page router passes no data to the template, which renders a static placeholder. Users cannot view their cart history.
