```python
from pydantic import BaseModel, Field
from typing import Optional

class ParsedListItem(BaseModel):
    """A structured item parsed from raw shopping list text."""
    name: str
    quantity: int = Field(default=1)
    unit: Optional[str] = None
    notes: Optional[str] = None

class ProductCandidate(BaseModel):
    """A Kroger product candidate for matching."""
    upc: str
    description: str
    brand: str
    size: str
    price_regular: Optional[float] = None
    price_promo: Optional[float] = None
    thumbnail_url: Optional[str] = None

class ItemMatch(BaseModel):
    """LLM match decision for one shopping list item."""
    list_item: str
    selected_upc: str
    selected_description: str
    selected_brand: str = ""
    selected_size: str = ""
    selected_price: Optional[float] = None
    selected_thumbnail: Optional[str] = None
    confidence: float = Field(ge=0.0, le=1.0)
    reasoning: str
    alternatives: list[str] = Field(default_factory=list)

class MatchResult(BaseModel):
    """Complete match result for all items in a shopping list."""
    matches: list[ItemMatch]

class ConfirmedItem(BaseModel):
    """A user-confirmed item ready for cart add."""
    upc: str
    description: str
    brand: str = ""
    size: str = ""
    quantity: int = 1
    price_regular: Optional[float] = None
    price_promo: Optional[float] = None
```

Add two new async functions to `app/services/kroger_client.py`, preserving all existing code:

**Function 1: `search_products()`**
```python
async def search_products(
    term: str,
    location_id: str,
    client_id: str,
    client_secret: str,
    limit: int = 10,
) -> list[dict]:
```
- Call `get_app_token(client_id, client_secret)` to get a client credentials token. If token retrieval fails, raise `RuntimeError` with the error message.
- GET `{KROGER_BASE}/products` with params: `filter.term` = term, `filter.locationId` = location_id, `filter.fulfillment` = `"csp"` (CRITICAL: lowercase `csp`, NOT `"curbside"` — per Pitfall 1), `filter.limit` = limit.
- Authorization header: `Bearer {app_token}`.
- Timeout: 10 seconds.
- Return `resp.json().get("data", [])` on success.
- On `httpx.HTTPStatusError`, raise `RuntimeError(f"Kroger product search failed: {e.response.status_code}")`.
- On `httpx.ConnectError`, raise `RuntimeError("Could not reach Kroger API")`.
- DO NOT persist results to any database (TOS constraint).

**Function 2: `add_to_cart()`**
```python
async def add_to_cart(
    items: list[dict],
    access_token: str,
) -> tuple[bool, str]:
```
- PUT `{KROGER_BASE}/cart/add` with JSON body `{"items": items}`. Each item in the list is `{"upc": "...", "quantity": N}`.
- Authorization header: `Bearer {access_token}` (user OAuth, NOT client credentials — per Pitfall 2).
- Content-Type: `application/json`.
- Timeout: 15 seconds.
- Success: `resp.status_code == 204` returns `(True, "Items added")`. CRITICAL: 204 No Content is the success response — do NOT parse response body (per Pitfall 3).
- Also accept 200 as success (defensive): `(True, "Items added")`.
- On 401: return `(False, "Kroger session expired. Please re-authenticate.")`.
- On other HTTP errors: return `(False, f"Cart add failed: {resp.status_code}")`.
- On `httpx.ConnectError`: return `(False, "Could not reach Kroger API")`.
