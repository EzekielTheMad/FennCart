## Spacing Scale

Declared values (must be multiples of 4). Identical to Phase 1 — no new exceptions for Phase 2.

| Token | Value | Tailwind Class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | `p-1` / `gap-1` | Icon gaps, badge padding, confidence indicator dot spacing |
| sm | 8px | `p-2` / `gap-2` | Compact table row padding, inline element spacing |
| md | 16px | `p-4` / `gap-4` | Default element spacing, form field gaps, card content padding |
| lg | 24px | `p-6` / `gap-6` | Product card padding, section spacing, review panel padding |
| xl | 32px | `p-8` / `gap-8` | Page content area padding, confirmation screen container |
| 2xl | 48px | `py-12` | Major section breaks between list input and review sections |
| 3xl | 64px | `py-16` | Success screen breathing room |

Exceptions:
- Touch targets for interactive elements: minimum 44px height (`min-h-[44px]`) — applies to confirm button, swap dropdown trigger, review toggle.
- Product thumbnail images: 64px × 64px (`w-16 h-16`) — off the standard spacing scale but aligns with Kroger product image dimensions.
- Confidence warning indicator dot: 8px diameter (`w-2 h-2`) — intentionally compact inline indicator.

**Source:** Phase 1 UI-SPEC (carried forward); exceptions derived from CONTEXT.md D-03 (product cards) and D-04 (confidence indicator).

## Typography

Identical to Phase 1 — no new sizes or weights introduced in Phase 2.

| Role | Size | Tailwind Class | Weight | Weight Class | Line Height |
|------|------|----------------|--------|--------------|-------------|
| Body | 16px | `text-base` | Regular (400) | `font-normal` | 1.5 (`leading-normal`) |
| Label | 14px | `text-sm` | Semibold (600) | `font-semibold` | 1.25 (`leading-tight`) |
| Heading | 20px | `text-xl` | Semibold (600) | `font-semibold` | 1.25 (`leading-tight`) |
| Display | 28px | `text-3xl` | Semibold (600) | `font-semibold` | 1.2 (`leading-snug`) |

Additional typographic patterns specific to Phase 2:
- **Product name in card:** `text-base font-semibold text-slate-100` (Label weight, Body size)
- **Product price:** `text-sm font-semibold text-slate-100`
- **Product size/unit:** `text-sm font-normal text-slate-400`
- **Confidence warning text:** `text-sm font-normal text-amber-400` — amber-400 (`#fbbf24`) used exclusively for the low-confidence label. Not a new semantic color: it appears only within the confidence flag; no 10% allocation shift.
- **Compact table row item name:** `text-sm font-normal text-slate-100`
- **Estimated total:** `text-xl font-semibold text-slate-100`

**Constraints:** Still exactly 4 sizes, 2 weights. Amber is a text-only accent within confidence flags — not a background fill.

**Source:** Phase 1 UI-SPEC (carried forward); Phase 2 patterns derived from CONTEXT.md D-03, D-04, D-06.

## Color

All colors are Tailwind utility classes referencing the default palette. No custom hex values. Dark mode only — no `dark:` variants needed.

| Role | Tailwind Tokens | Usage |
|------|----------------|-------|
| Dominant (60%) | `bg-slate-950` | Page background |
| Secondary (30%) | `bg-slate-900` / `bg-slate-800` / `bg-slate-700` | Sidebar, product cards, compact review rows, textarea background, dropdown backgrounds |
| Accent (10%) | `bg-green-600` / `text-green-500` / `border-green-500` | Reserved elements listed below |
| Destructive | `bg-red-600` / `text-red-400` / `bg-red-950 border-red-800` | Error states only |

**Accent reserved for (explicit list):**
1. Primary CTA button: "Build my cart" (list input step)
2. Primary CTA button: "Add to cart" (review confirmation step)
3. Active nav item indicator (inherited from Phase 1 sidebar)
4. Auto-matched item checkmark indicator (high-confidence items shown as already accepted)
5. Success screen: item count badge and "Open Fry's curbside" link

**Accent is NOT used for:** product card borders, swap dropdown triggers, toggle controls, informational text, loading spinners, or confidence flags.

**Confidence flag color:** `text-amber-400` / `bg-amber-950 border-amber-800` — amber is used exclusively for the low-confidence warning indicator on product cards. It is not a fourth semantic color allocation; it is a narrowly scoped inline text/badge pattern.

**Text colors (carried from Phase 1):**
- Primary text: `text-slate-100`
- Secondary/muted text: `text-slate-400`
- Input text: `text-slate-100` on `bg-slate-800`
- Placeholder text: `text-slate-500`
- Error text: `text-red-400`

**Source:** Phase 1 UI-SPEC (carried forward); accent list updated for Phase 2 CTAs per CONTEXT.md D-05, D-06; confidence flag per CONTEXT.md D-04.

## Interaction Contracts

### Shopping List Input Flow

**Layout:** Single-column layout within the main content area. Textarea at top, live preview below, submit button below preview. No sidebar column — full-width content within the `<main>` element.

| Element | Specification |
|---------|--------------|
| Textarea | `bg-slate-800 border border-slate-700 rounded-lg text-slate-100 text-base p-4 w-full min-h-[160px] resize-y` — resizable vertically, min 160px |
| Textarea placeholder | `Start typing your list — one item per line. For example: milk, 2% • eggs, a dozen • that pasta Jen likes` |
| Live preview region | HTMX partial swap into `#list-preview` on 400ms debounced input. Shows structured items (name, quantity, notes) as `bg-slate-800 rounded p-3` pill list |
| Preview item format | Name in `text-sm font-semibold text-slate-100` + quantity in `text-sm text-slate-400 ml-2` |
| Submit button | Full-width `bg-green-600 hover:bg-green-700 disabled:opacity-60 text-white font-semibold py-3 px-4 rounded-lg` |
| Submit button label | `Build my cart` |
| Submit disabled state | Disabled while list is empty (fewer than 2 non-whitespace characters) |

**Source:** CONTEXT.md D-01 (smart textarea with live preview), D-02 (no persistence), REQUIREMENTS.md SRCH-01.

### Processing / Loading State

**Decision (Claude's discretion):** Full-content replacement with a centered spinner + progress message. The list input area is replaced by a loading state in the same `#shopping-content` target. User cannot submit again during processing.

| Element | Specification |
|---------|--------------|
| Container | `flex flex-col items-center justify-center min-h-[300px] gap-4` |
| Spinner | SVG animate-spin, `w-8 h-8 text-green-500` |
| Primary message | `text-base font-semibold text-slate-100` — `Matching your items…` |
| Secondary message | `text-sm text-slate-400` — `This takes a few seconds while FennCart searches Kroger for each item.` |

**Source:** CONTEXT.md D-08 (all-at-once results display, not streaming).

### Review Screen Layout

**Decision (CONTEXT.md D-03):** Hybrid layout. Low-confidence items (needing review) render as product cards. High-confidence items (auto-matched) render as compact table rows. These two zones stack vertically: cards zone on top, table zone below.

**Zone 1 — Review Cards (low-confidence items):**

| Element | Specification |
|---------|--------------|
| Zone heading | `text-xl font-semibold text-slate-100 mb-4` — `Review these matches` |
| Zone subheading | `text-sm text-slate-400 mb-6` — `FennCart wasn't certain about these items. Pick the right product or swap to an alternative.` |
| Card container | `bg-slate-800 border border-slate-700 rounded-lg p-4 flex gap-4 items-start` |
| Card list | `space-y-3` |
| Product thumbnail | `w-16 h-16 rounded object-contain bg-slate-700` — 64×64px, slate-700 fallback bg when no image |
| Product name | `text-base font-semibold text-slate-100` |
| Product size/unit | `text-sm text-slate-400` |
| Product price | `text-sm font-semibold text-slate-100` |
| Confidence warning | `inline-flex items-center gap-1 text-sm text-amber-400` + amber dot `w-2 h-2 bg-amber-400 rounded-full` — `Uncertain match` |
| Swap button | `text-sm text-slate-400 hover:text-slate-100 underline` — `Choose a different product` |
| Swap dropdown | Alpine.js `x-show` disclosure, `bg-slate-800 border border-slate-700 rounded-lg shadow-lg` — lists 3-5 alternatives as clickable rows; HTMX partial swap on selection |
| Swap alternative row | `flex items-center gap-3 p-3 hover:bg-slate-700 cursor-pointer rounded` |

**Zone 2 — Auto-Matched Items (high-confidence):**

| Element | Specification |
|---------|--------------|
| Zone heading | `text-xl font-semibold text-slate-100 mb-4` (shown only if zone has items) — `Auto-matched` |
| Zone description | `text-sm text-slate-400 mb-4` — `These items matched with high confidence and are ready to add.` |
| Toggle button | `text-sm text-slate-400 hover:text-slate-100` — `Show all {N} items` / `Hide` — Alpine.js toggle |
| Table | `w-full text-sm` with `border-collapse` |
| Table row | `border-b border-slate-700 py-2` — item name, size, price in three columns |
| Accepted checkmark | `text-green-500` Heroicons check-circle icon, `w-4 h-4`, rightmost column |

**Review Mode Toggle (SRCH-05):**

A toggle control appears above both zones when both zones have content. It switches between "Exceptions only" (default) and "Full review" (shows all items as cards).

| Element | Specification |
|---------|--------------|
| Toggle container | `flex items-center gap-3 mb-6` |
| Toggle label | `text-sm text-slate-400` — `Review mode:` |
| Toggle control | Two-button pill: `bg-slate-800 rounded-full p-1 flex gap-1` — each option is `text-sm px-3 py-1 rounded-full` — active state `bg-slate-600 text-slate-100`, inactive `text-slate-400 hover:text-slate-100` |
| Option 1 label | `Exceptions only` |
| Option 2 label | `Full review` |

**Source:** CONTEXT.md D-03, D-04, D-05, REQUIREMENTS.md SRCH-03, SRCH-04, SRCH-05.

### Error UX Pattern (Phase 2)

Inherits Phase 1 inline error approach. HTMX partial swaps handle all error states — no full page reloads for recoverable errors.

| Context | Pattern | Copy |
|---------|---------|------|
| Empty list submitted | Inline error above the textarea | `Your list is empty. Paste or type at least one item to get started.` |
| List too short (under 2 chars) | Submit button stays disabled | Not an error state — button simply stays disabled |
| LLM matching failed | Replaces loading spinner | Error container: `bg-red-950 border border-red-800 rounded-lg p-6 text-center` — heading `text-base font-semibold text-red-400` `Matching failed` — body `text-sm text-slate-400` `{specific error}. Try again or check your LLM settings.` — retry button `bg-slate-700 hover:bg-slate-600 text-slate-100 font-semibold py-2 px-4 rounded-lg mt-4` `Try again` |
| Kroger Products API error | Same error container as LLM failure — `Could not reach Kroger. Check your connection and try again.` + `Try again` button |
| Kroger token expired (silent refresh fails) | Inline banner at top of page: `bg-red-950 border-b border-red-800 p-3 text-sm text-red-400` — `Your Kroger session expired. Reconnect in Settings.` — link `text-red-300 underline` `Go to Settings` |
| Cart add failed (partial) | Below the success heading, amber banner: `bg-amber-950 border border-amber-800 rounded p-3 text-sm text-amber-400` — `{N} of {M} items could not be added. Try re-adding from your cart history.` |
| Cart add failed (total) | Replaces success screen with same error container pattern — `Could not add items to your cart. Kroger may be temporarily unavailable. Your selections were not saved.` + `Try again` button |

**Source:** REQUIREMENTS.md CART-01, CART-02; CONTEXT.md Claude's Discretion (retry vs report pattern resolved as inline retry-in-place); Phase 1 UI-SPEC error patterns (carried forward).
