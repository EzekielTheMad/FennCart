**1. Add a new function `parse_preference_nl` to `app/routers/preferences.py` (or a separate helper in the same file):**

This function uses Instructor to interpret a natural language preference update.

```python
async def parse_preference_nl(
    conversation_history: list[dict],
    api_key: str,
    provider: str,
    model: str,
) -> PreferenceDelta:
    """Parse a natural language preference update into a structured delta."""
    model_str = f"{provider}/{model}" if "/" not in model else model
    client = instructor.from_provider(f"litellm/{model_str}", async_client=True)

    system_prompt = (
        "You are a preference update assistant for a grocery shopping app. "
        "The user wants to update their brand/product preferences. "
        "Interpret their message and return a structured action. "
        "If the intent is unclear, set action='clarify' and ask a specific question. "
        "For clear intents: use 'replace' to switch brands, 'add' to add a new preference, "
        "'remove' to delete a preference. Always include a human_summary describing the change."
    )

    messages = [{"role": "system", "content": system_prompt}] + conversation_history

    return await client.create(
        messages=messages,
        response_model=PreferenceDelta,
        max_tokens=500,
        max_retries=2,
        api_key=api_key,
    )
```

**2. Add two new endpoints to `app/routers/preferences.py`:**

**a) `POST /preferences/chat` — process a chat message**
- Parse form: `message: str = Form(...)`
- Load conversation history from session: `request.session.get("pref_chat_history", [])`
- Append user message: `history.append({"role": "user", "content": message})`
- Cap LLM context at last 10 messages (Pitfall 5): `llm_history = history[-10:]`
- Load settings: `settings = get_settings()`
- Call `parse_preference_nl(llm_history, settings.llm_api_key, settings.llm_provider, settings.llm_model)`
- Append assistant response to history: `history.append({"role": "assistant", "content": delta.human_summary})`
- Save updated history to session: `request.session["pref_chat_history"] = history`
- If `delta.action == "clarify"`: return chat_message.html with `needs_confirm=False`, `message=delta.clarification_question`, `role="assistant"`
- Otherwise: store delta in session `request.session["pending_delta"] = delta.model_dump()`, return chat_message.html with `needs_confirm=True`, `message=delta.human_summary`, `role="assistant"`, `delta=delta.model_dump()`
- Also return the user message bubble first (two message bubbles in one response — user bubble + assistant bubble), OR return only the assistant bubble and have the client-side JavaScript add the user bubble before the HTMX swap. The simpler approach: return BOTH bubbles in a single HTML response (user bubble div + assistant bubble div), since `hx-swap="beforeend"` appends all returned HTML.

**b) `POST /preferences/chat/apply` — apply a confirmed NL delta**
- Load `pending_delta` from session
- Reconstruct `PreferenceDelta` from the dict
- Call `PreferenceService(db).apply_nl_delta(delta)`
- Clear `pending_delta` from session
- Return chat_message.html with `role="system"`, `message="Done! Your preferences have been updated."`, `needs_confirm=False`
