**Change 1: Rewrite the outer `x-data` declaration (currently lines 7-16) to initialize `confirmedItems` from Jinja2 server-rendered data instead of the never-passed `confirmed_items_json` context variable.**

Replace lines 7-16:
```html
<div x-data="{
    mode: '{{ review_mode | default("exceptions") }}',
    confirmedItems: {{ confirmed_items_json | default('[]') | tojson }},
    updateItem(upc, description, brand, size, price, quantity) {
        const idx = this.confirmedItems.findIndex(i => i.list_item === description);
        if (idx >= 0) {
            this.confirmedItems[idx].upc = upc;
        }
    }
}" id="shopping-content">
```

With:
```html
<div x-data="{
    mode: '{{ review_mode | default("exceptions") }}',
    confirmedItems: [
        {% for item in review_items %}
        {
            list_item: '{{ item.list_item | e }}',
            upc: '{{ item.selected_upc }}',
            description: '{{ item.selected_description | e }}',
            brand: '{{ item.selected_brand | e }}',
            size: '{{ item.selected_size | e }}',
            quantity: 1,
            price: {{ item.selected_price if item.selected_price is not none else 'null' }}
        }{% if not loop.last or auto_items %},{% endif %}
        {% endfor %}
        {% for item in auto_items %}
        {
            list_item: '{{ item.list_item | e }}',
            upc: '{{ item.selected_upc }}',
            description: '{{ item.selected_description | e }}',
            brand: '{{ item.selected_brand | e }}',
            size: '{{ item.selected_size | e }}',
            quantity: 1,
            price: {{ item.selected_price if item.selected_price is not none else 'null' }}
        }{% if not loop.last %},{% endif %}
        {% endfor %}
    ],
    updateItem(listItem, newUpc) {
        const idx = this.confirmedItems.findIndex(i => i.list_item === listItem);
        if (idx >= 0) { this.confirmedItems[idx].upc = newUpc; }
    }
}" id="shopping-content">
```

Key differences from old code:
- `confirmedItems` is populated from `review_items` + `auto_items` Jinja2 loops (not the never-passed `confirmed_items_json`)
- `updateItem` takes `(listItem, newUpc)` — uses `list_item` as the lookup key, updates only the `upc` field
- Each item includes `list_item` as the stable identifier for `findIndex`

**Change 2: Add `$root.updateItem()` call to each card's swap `@click` handler (currently lines 100-107).**

Replace the `@click` handler on each swap candidate div:

```html
@click="
    selectedUpc = '{{ candidate.upc }}';
```

With (add `$root.updateItem` call at the end):
```html
@click="
    selectedUpc = '{{ candidate.upc }}';
    selectedDesc = '{{ candidate.description | e }}';
    selectedBrand = '{{ candidate.brand | e }}';
    selectedSize = '{{ candidate.size | e }}';
    selectedPrice = {{ candidate.price_regular if candidate.price_regular is not none else 'null' }};
    open = false;
    $root.updateItem('{{ item.list_item | e }}', '{{ candidate.upc }}')
"
```

The `$root` magic property refers to the closest ancestor element with `x-data`, which is `#shopping-content`. This is a documented, stable Alpine.js 3 API.

**Change 3: Replace the entire hidden input (currently lines 207-238) that uses `_x_dataStack` with a simple `confirmedItems` reference.**

Replace lines 207-238 (the entire `<input type="hidden" ... :value="JSON.stringify([...])">` block) with:
```html
        {# Hidden input: JSON array of ConfirmedItem dicts from Alpine state #}
        <input type="hidden"
               name="confirmed_items_json"
```
