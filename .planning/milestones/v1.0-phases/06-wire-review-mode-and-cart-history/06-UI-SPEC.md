## Component Contracts

### History Page — Session Rows (CART-03)

The `/history` page replaces the centered placeholder with a full-height content layout matching the existing page pattern.

**Layout:**
- Page uses `max-w-3xl mx-auto px-6 py-8` container (consistent with settings page pattern)
- Page heading: `text-xl font-semibold text-slate-100` — "Shopping history"
- Supporting line: `text-sm text-slate-400 mb-6` — session count or descriptive copy

**Session row (collapsed):**
- Container: `bg-slate-800 border border-slate-700 rounded-lg` with `cursor-pointer`
- Layout: single row, `flex items-center justify-between px-4 py-3`
- Left content: formatted date + item count + estimated total in one line
  - Date: `text-sm font-semibold text-slate-100` — formatted as "Apr 6, 2026"
  - Separator: `text-slate-600` bullet `&bull;`
  - Item count: `text-sm text-slate-400` — "12 items"
  - Separator: `text-slate-600` bullet `&bull;`
  - Total: `text-sm text-slate-400` — "$47.82"
- Right content: chevron icon (`w-4 h-4 text-slate-400`), rotates 180deg when expanded via Alpine `:class`
- Touch target: full row is the click/tap target via Alpine `@click`

**Session row (expanded) — item detail table:**
- Expands below the header row within the same card container
- Top border: `border-t border-slate-700 mt-1`
- Table: `w-full text-sm` with `border-collapse`
- Columns: product name (`text-slate-100 text-left`), brand (`text-slate-400`), qty (`text-slate-400 text-right`), price (`text-slate-100 text-right`)
- Row divider: `border-b border-slate-700 py-2`
- Price display: show `price_promo` when non-null, otherwise `price_regular`; show `—` when both null
- Expand/collapse: Alpine.js `x-data="{ open: false }"` on each session row, `x-show="open"` on detail panel, `x-transition` for smooth reveal
- No HTMX needed — data is server-rendered into the template; Alpine handles show/hide client-side

**Sessions sorted:** newest-first (server-side `ORDER BY created_at DESC`)

**Space between rows:** `space-y-3` on the session list container

### History Page — Empty State

Shown when `CartSession` table returns zero rows.

- Centered layout: `flex items-center justify-center min-h-[60vh]`
- Container: `text-center max-w-sm`
- Icon: clock/history Heroicon, `w-10 h-10 text-slate-600 mx-auto mb-4`
- Heading: `text-xl font-semibold text-slate-100 mb-2` — "No shopping history yet"
- Body: `text-sm text-slate-400 mb-6` — "Your cart history will appear here after your first shopping run."
- CTA link: `text-green-500 hover:text-green-400 text-sm underline` — "Start shopping"  href="/shopping"

### Review Mode Toggle (SRCH-05)

No visual change to the toggle itself. The only contract change is initialization:

- `x-data` on the `#shopping-content` div must initialize `mode` from a server-passed variable:
  `mode: '{{ review_mode | default("exceptions") }}'`
  instead of the hardcoded `mode: 'exceptions'`
- Valid values: `'exceptions'` (default) and `'full'`
- Toggle buttons, zones, and all other Alpine state remain unchanged
- The server-passed `review_mode` comes from `AppConfig.review_mode` queried in the shopping router

## Interaction Contracts

### Expand/Collapse Behavior

- Mechanism: Alpine.js `x-data="{ open: false }"` per session row, `x-show="open" x-transition` on detail panel
- Chevron rotation: `:class="open ? 'rotate-180' : ''"` with `transition-transform duration-200`
- No HTMX partial fetch — data is fully server-rendered at page load, Alpine toggles visibility only
- Only one row needs to be open at a time: no constraint enforced (multiple rows can be expanded simultaneously; simpler for a history view)

### Review Mode Persistence

- At `/shopping/review` render time, shopping router queries `AppConfig.review_mode` via `AsyncSession`
- Value passed to template context as `review_mode` (string: `"exceptions"` or `"full"`)
- Alpine `x-data` initializes with `mode: '{{ review_mode }}'`
- Toggle remains client-side only during the shopping run — no POST back to AppConfig
- Settings page (`/settings` → preferences section) remains the canonical place to change the default

### Price Display Logic

For `CartItem` rows in the expanded history detail:
- Show `price_promo` when non-null (promotional price takes precedence)
- Fall back to `price_regular` when `price_promo` is null
- Show `—` when both are null
