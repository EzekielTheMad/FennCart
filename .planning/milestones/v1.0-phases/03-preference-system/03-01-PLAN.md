```python
from typing import Optional
from pydantic import BaseModel, Field

class ReceiptLineItem(BaseModel):
    """Single line item parsed from a receipt PDF."""
    product_name: str
    brand: str = ""
    product_category: str
    quantity: int = 1
    size: str = ""
    price: Optional[float] = None
    confidence: float = Field(ge=0.0, le=1.0)

class ParsedReceipt(BaseModel):
    """Instructor response model for receipt parsing."""
    items: list[ReceiptLineItem]
    parse_warnings: list[str] = Field(default_factory=list)

class ContradictionCandidate(BaseModel):
    """A detected brand contradiction for user resolution (D-06)."""
    category: str
    existing_brand: str
    existing_count: int
    new_brand: str
    product_name: str
    new_item_index: int          # Index into the parsed items list
    resolution: Optional[str] = None  # "new_preference" | "one_time"

class PreferenceDelta(BaseModel):
    """Structured interpretation of a natural language preference update (D-07, D-08)."""
    action: str                  # "replace" | "add" | "remove" | "clarify"
    category: str = ""
    old_brand: Optional[str] = None
    new_brand: Optional[str] = None
    product_name: Optional[str] = None
    clarification_question: Optional[str] = None
    human_summary: str

class PreferenceCreateRequest(BaseModel):
    """Request body for manually adding a preference."""
    product_category: str
    brand: str
    product_name: str
    notes: Optional[str] = None

class PreferenceUpdateRequest(BaseModel):
    """Request body for editing an existing preference."""
    product_name: Optional[str] = None
    brand: Optional[str] = None
    product_category: Optional[str] = None
    notes: Optional[str] = None
```

**1. Create `app/services/preference_service.py`:**

Class `PreferenceService` with `__init__(self, db: AsyncSession)`. Methods:

**a) `async def upsert_from_receipt_item(self, item: ReceiptLineItem, is_one_time: bool = False) -> PreferenceEntry`**
- Query for existing entry matching `(product_category, brand, product_name)` using `select(PreferenceEntry).where(and_(...))`.
- If exists and not is_one_time: increment `purchase_count`, update `last_seen_at` and `updated_at` to `datetime.utcnow()`.
- If exists and is_one_time: do not increment (user chose "one-time substitution" at D-06).
- If not exists: create new entry with `purchase_count=1`, `source="receipt"`.
- `self.db.add(entry)` then `await self.db.flush()`. Return the entry.

**b) `async def detect_contradictions(self, items: list[ReceiptLineItem]) -> tuple[list[ReceiptLineItem], list[ContradictionCandidate]]`**
- For each item, query for existing PreferenceEntry in the same `product_category` with `purchase_count >= 2` and a DIFFERENT `brand`.
- If found: create a `ContradictionCandidate` with `existing_brand`, `existing_count`, `new_brand=item.brand`, `new_item_index=index`.
- Return `(clean_items, contradictions)` where clean_items are those without contradictions.
- Items with empty brand ("") never trigger contradictions.

**c) `async def get_preferences_for_matching(self) -> dict`**
- Query all PreferenceEntry where `purchase_count >= 2`, ordered by `purchase_count DESC, last_seen_at DESC`, limit 50.
- Return dict: `{"entries": [{"category": e.product_category, "brand": e.brand, "product": e.product_name, "strength": "strong" if e.purchase_count >= 3 else "moderate"} for e in entries]}`
- If no entries with count >= 2, return `{"entries": []}`.
- Add comment: "Preference signals come ONLY from user-uploaded receipts and manual entries. Never from cart_items or Kroger API responses (TOS)."

**d) `async def list_preferences(self, query: Optional[str] = None) -> list[PreferenceEntry]`**
- If query: `select(PreferenceEntry).where(or_(PreferenceEntry.product_name.ilike(f"%{query}%"), PreferenceEntry.brand.ilike(f"%{query}%"), PreferenceEntry.product_category.ilike(f"%{query}%")))`.
- Order by `purchase_count DESC, updated_at DESC`.
- Return list of all matching entries.

**e) `async def get_preference(self, pref_id: int) -> Optional[PreferenceEntry]`**
- Simple select by id.

**f) `async def create_preference(self, data: PreferenceCreateRequest) -> PreferenceEntry`**
- Create new PreferenceEntry with `source="manual"`, `purchase_count=1`.

**g) `async def update_preference(self, pref_id: int, data: PreferenceUpdateRequest) -> Optional[PreferenceEntry]`**
- Load by id, update non-None fields from data, set `updated_at=datetime.utcnow()`.

**h) `async def delete_preference(self, pref_id: int) -> bool`**
- Delete by id, return True if found and deleted.

**i) `async def bulk_delete(self, ids: list[int]) -> int`**
- Delete all entries with id in ids. Return count deleted.

**j) `async def apply_nl_delta(self, delta: PreferenceDelta) -> Optional[PreferenceEntry]`**
- Handle delta.action:
  - "add": create new entry with `source="nl_chat"`, `product_category=delta.category`, `brand=delta.new_brand`, `product_name=delta.product_name or delta.category`.
  - "remove": find entry by category+brand, delete it, return None.
  - "replace": find entry by category+old_brand, update brand to new_brand, set `source="nl_chat"`, `updated_at=now()`.
  - "clarify": should never reach this method (handled in router).
