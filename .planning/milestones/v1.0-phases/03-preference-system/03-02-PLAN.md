**1. Create `app/routers/preferences.py`:**

Router-local Jinja2Templates (matching shopping.py pattern). Prefix: `/preferences`.

Endpoints:

**a) `GET /preferences/list` — HTMX preference list partial**
- Query param: `q: Optional[str] = None`
- Call `PreferenceService(db).list_preferences(query=q)`
- Return `partials/pref_list.html` with `{"request": request, "preferences": entries, "query": q}`
- Target: `#pref-list-container`, Trigger: search input 300ms debounce

**b) `GET /preferences/{pref_id}/row` — single preference row partial**
- Call `PreferenceService(db).get_preference(pref_id)`
- Return `partials/pref_row.html` with `{"request": request, "pref": entry}`
- Used for: cancel edit, after save

**c) `GET /preferences/{pref_id}/edit-form` — inline edit form partial**
- Call `PreferenceService(db).get_preference(pref_id)`
- Return `partials/pref_edit_form.html` with `{"request": request, "pref": entry}`

**d) `PUT /preferences/{pref_id}` — update preference**
- Parse form fields: `product_name: str = Form(...)`, `brand: str = Form(...)`, `product_category: str = Form(...)`, `notes: str = Form("")`
- Create PreferenceUpdateRequest and call `PreferenceService(db).update_preference(pref_id, data)`
- Return `partials/pref_row.html` with updated entry

**e) `POST /preferences/create` — add new preference**
- Parse form fields: `product_name, brand, product_category, notes`
- Create PreferenceCreateRequest and call `PreferenceService(db).create_preference(data)`
- Return `partials/pref_row.html` with new entry
- HTMX target: prepend to list container

**f) `DELETE /preferences/{pref_id}` — delete single preference**
- Call `PreferenceService(db).delete_preference(pref_id)`
- Return empty string (HTMX removes the row via `hx-swap="outerHTML"`)

**g) `POST /preferences/bulk-delete` — bulk delete**
- Parse form: `ids: str = Form(...)` (comma-separated IDs)
- Split, convert to int list, call `PreferenceService(db).bulk_delete(id_list)`
- Return full `partials/pref_list.html` (refresh the entire list)

**h) `POST /preferences/upload` — receipt upload and parse**
- Accept `receipt_pdf: UploadFile = File(...)`
- Read bytes: `pdf_bytes = await receipt_pdf.read()`
- Call `extract_receipt_text(pdf_bytes)` -> `(raw_text, extract_warnings)`
- If `len(raw_text.strip()) < 50`: return `partials/receipt_review.html` with `error=True`, `error_heading="Could not read this receipt"`, `error_body="FennCart couldn't extract items from this PDF. Try a different receipt format, or add preferences manually."`
- Load LLM config from Settings via `get_settings()`
- Call `parse_receipt_with_llm(raw_text, settings.llm_api_key, settings.llm_provider, settings.llm_model)`
- Call `PreferenceService(db).detect_contradictions(parsed.items)`
- Create ReceiptUpload record: `filename=receipt_pdf.filename`, `items_extracted=len(parsed.items)`, `parse_status="parsed"`, `parse_warnings=json.dumps(parsed.parse_warnings + extract_warnings)`
- Store parsed items and contradictions in session: `request.session["receipt_items"] = [item.model_dump() for item in parsed.items]`, `request.session["receipt_contradictions"] = [c.model_dump() for c in contradictions]`, `request.session["receipt_upload_id"] = upload.id`
- Return `partials/receipt_review.html` with `{"request": request, "items": parsed.items, "contradictions": contradictions, "warnings": parsed.parse_warnings + extract_warnings, "upload_id": upload.id}`

**i) `POST /preferences/receipt/resolve` — resolve a contradiction**
- Parse form: `contradiction_index: int = Form(...)`, `resolution: str = Form(...)` (either "new_preference" or "one_time")
- Load contradictions from session, mark the one at index as resolved
- Update session
- Return updated `partials/receipt_contradictions.html` (or empty if all resolved)

**j) `POST /preferences/receipt/save` — save confirmed receipt items**
- Load items from session: `request.session["receipt_items"]`
- Load contradictions from session (with resolutions)
- For each item: call `PreferenceService(db).upsert_from_receipt_item(item, is_one_time=...)` based on contradiction resolution
- Update ReceiptUpload: `parse_status="confirmed"`, `items_confirmed=count`
- Clear session keys
- Return `partials/pref_list.html` (show the updated preference list in the receipt panel, with a success message)

All endpoints use `db: AsyncSession = Depends(get_session)` for dependency injection.
All endpoints returning HTML use `response_class=HTMLResponse`.
