**Mock helpers:**
- Patch `app.services.cart_service.search_products` to return a fixed list of product dicts matching the Kroger API shape (with productId, description, brand, items[0].size, items[0].price.regular, images, fulfillment).

- Patch `app.services.cart_service.match_products` to return a `MatchResult` with known confidence values.
- Patch `app.services.cart_service.add_to_cart` to return `(True, "Items added")`.

**Tests:**

1. `test_confidence_partitioning` (SRCH-04) — Create a MatchResult with 3 matches: confidence 0.95, 0.75, 0.85. Call `partition_matches()`. Assert review_items has 1 item (the 0.75 one), auto_items has 2 items (0.95 and 0.85). The threshold is 0.8: `>= 0.8` is auto, `< 0.8` is review.

2. `test_process_list_calls_search_and_match` (SRCH-02) — Mock everything, call `process_list("milk\neggs")`. Assert `parse_shopping_list` was called once. Assert `search_products` was called (at least once per parsed item). Assert `match_products` was called once. Assert result is a tuple of (MatchResult, dict).

3. `test_search_deduplication` — Mock parse to return two items with same name "milk". Call `process_list`. Assert `search_products` was called only once for "milk" (dedup within session).

4. `test_cart_items_persisted` (CART-02) — Create confirmed items, mock `add_to_cart` returning success. Call `add_confirmed_to_cart`. Query the test DB for CartSession and CartItem records. Assert CartSession exists with correct item_count. Assert CartItems exist with correct UPCs and session_id FK.

5. `test_cart_items_persisted_on_failure` — Mock `add_to_cart` returning `(False, "error")`. Call `add_confirmed_to_cart`. Assert CartItems are still saved to DB (local shadow persists even on Kroger failure). Assert fail_count equals len(confirmed).

6. `test_get_session_items` (CART-03) — Create a CartSession and CartItems in DB. Call `get_session_items(session_id)`. Assert returns the session and correct item list.

7. `test_to_candidate_extracts_fields` — Call `CartService._to_candidate()` with a mock Kroger product dict. Assert all fields mapped correctly: upc from productId, description, brand, size from items[0], price from items[0].price.regular, thumbnail from images.
