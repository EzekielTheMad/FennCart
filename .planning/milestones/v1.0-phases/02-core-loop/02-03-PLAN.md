**Class: CartService**
```python
class CartService:
    def __init__(
        self,
        db: AsyncSession,
        location_id: str,
        kroger_client_id: str,
        kroger_client_secret: str,
        llm_api_key: str,
        llm_provider: str = "anthropic",
        llm_model: str = "claude-3-haiku-20240307",
    ):
```
Store all params as instance attributes.

**Method: `process_list(raw_text, preferences=None) -> tuple[MatchResult, dict[str, list[ProductCandidate]]]`**
1. Call `parse_shopping_list(raw_text, self.llm_api_key, self.llm_provider, self.llm_model)` to get `parsed_items: list[ParsedListItem]`.
2. For each parsed item, call `search_products(item.name, self.location_id, self.kroger_client_id, self.kroger_client_secret, limit=10)` to get raw product dicts. Use an in-memory `search_cache: dict[str, list[dict]]` keyed by `item.name.lower().strip()` to deduplicate Kroger API calls within a single session (per Pitfall 7 — TOS-safe, not persistent).
3. Convert raw product dicts to `ProductCandidate` objects using a `_to_candidate(product_dict)` static method that extracts: `upc` = `product_dict["productId"]`, `description` = `product_dict["description"]`, `brand` = `product_dict.get("brand", "")`, `size` = first item's size from `product_dict["items"][0]["size"]` if items exist else `""`, `price_regular` = first item's `price.regular` if exists else None, `price_promo` = first item's `price.promo` if exists else None, `thumbnail_url` = first image with perspective "front" -> first size with size "thumbnail" -> url, else None.
4. Build `candidates_dict: dict[str, list[ProductCandidate]]` mapping each item name to its candidate list.
5. Call `match_products(parsed_items, candidates_dict, self.llm_api_key, self.llm_provider, self.llm_model, preferences=preferences)` to get `match_result: MatchResult`.
6. Return `(match_result, candidates_dict)` — the candidates_dict is needed by the router for the swap dropdown alternatives.

**Method: `partition_matches(match_result) -> tuple[list[ItemMatch], list[ItemMatch]]`**
Split `match_result.matches` into two lists:
- `review_items`: matches with `confidence < 0.8`
- `auto_items`: matches with `confidence >= 0.8`
Return `(review_items, auto_items)`.

**Method: `add_confirmed_to_cart(confirmed_items, access_token) -> tuple[CartSession, int, int, str]`**
1. Calculate `estimated_total = sum(item.price_regular * item.quantity for item in confirmed_items if item.price_regular)`.
2. Create `CartSession(item_count=len(confirmed_items), estimated_total=estimated_total)`.
3. Add session to DB, flush to get ID.
4. Build cart payload: `[{"upc": item.upc, "quantity": item.quantity} for item in confirmed_items]`.
5. Call `add_to_cart(cart_payload, access_token)`.
6. If success: create `CartItem` for each confirmed item with `session_id=session.id`, commit, return `(session, len(confirmed_items), 0, "")`.
7. If failure: still save CartItems to local DB (user wants record even if Kroger call failed), commit, return `(session, 0, len(confirmed_items), error_message)`.

**Method: `get_session_items(session_id) -> tuple[CartSession, list[CartItem]]`**
Query CartSession by id, query CartItems by session_id, return both. Used by success screen.

**Static method: `_to_candidate(product_dict) -> ProductCandidate`**
Extract fields as described in step 3 above. Defensive: use `.get()` throughout, handle missing nested fields gracefully.

**Endpoint 1: `GET /shopping`** — Renders the shopping list input page.
- Returns `templates.TemplateResponse(request, "pages/shopping.html", {"active_page": "shopping"})`.

**Endpoint 2: `POST /shopping/preview`** — HTMX partial for live list preview (D-01).
- Accepts `list_text: str = Form("")`.
- Does a lightweight regex-based parse (NOT LLM — this is the debounced live preview, must be fast): split by newlines, strip empties, extract quantity if line starts with a number. Return each line as `{"name": ..., "quantity": ...}`.
- Returns `templates.TemplateResponse(request, "partials/list_preview.html", {"items": parsed_items})`.
- If list_text is empty or only whitespace, return empty HTML response.

**Endpoint 3: `POST /shopping/match`** — Main pipeline: parse list + search Kroger + LLM match.
- Accepts `list_text: str = Form(...)`.
- If list_text.strip() is empty or len < 2, return error partial: `templates.TemplateResponse(request, "partials/error_block.html", {"error_heading": "Your list is empty", "error_body": "Paste or type at least one item to get started.", "show_retry": False})`.
- Get settings via `get_settings()`. Get DB session via dependency.
- Instantiate `CartService(db=session, location_id=location_id, kroger_client_id=settings.kroger_client_id, kroger_client_secret=settings.kroger_client_secret, llm_api_key=settings.llm_api_key, llm_provider=settings.llm_provider, llm_model=settings.llm_model)`.
- For location_id: query `AppConfig` from DB to get `store_location_id`. Import `from app.models.config_model import AppConfig` and `from sqlalchemy import select`.
- Call `cart_service.process_list(list_text)` to get `(match_result, candidates_dict)`.
- Call `cart_service.partition_matches(match_result)` to get `(review_items, auto_items)`.
- Build a `candidates_lookup: dict[str, list[ProductCandidate]]` for the swap dropdown — map each alternative UPC in review_items to its ProductCandidate from candidates_dict.
- Store match_result and candidates in server-side session (Starlette session middleware): `request.session["match_data"] = match_result.model_dump_json()` and `request.session["candidates"] = json.dumps({k: [c.model_dump() for c in v] for k, v in candidates_dict.items()})`. This allows the swap and confirm endpoints to access the data without re-running the pipeline.
- Return `templates.TemplateResponse(request, "partials/review_screen.html", {"review_items": review_items, "auto_items": auto_items, "candidates_dict": candidates_dict, "total_items": len(match_result.matches)})`.
- Wrap the pipeline in try/except. On `RuntimeError`, return `templates.TemplateResponse(request, "partials/error_block.html", {"error_heading": "Matching failed", "error_body": str(e) + ". Try again or check your LLM settings.", "show_retry": True})`.

**Endpoint 4: `POST /shopping/swap`** — HTMX partial swap for alternative product (D-05).
- Accepts `item_name: str = Form(...)`, `new_upc: str = Form(...)`.
- Load candidates from session: `candidates_dict = json.loads(request.session.get("candidates", "{}"))`.
- Find the ProductCandidate matching new_upc in the candidates for item_name.
- Return a partial HTML snippet rendering the updated product card with the new selection.

**Endpoint 5: `POST /shopping/add-to-cart`** — Confirm and add to Kroger cart (CART-01).
- Accepts form data: `confirmed_items_json: str = Form(...)` — JSON string of list of ConfirmedItem dicts.
- Parse into `list[ConfirmedItem]` via Pydantic.
- Get user OAuth token: `access_token = await get_valid_access_token(session)`.
- If access_token is None, return error partial with "Your Kroger session expired. Reconnect in Settings." and a link to `/setup`.
- Instantiate CartService, call `add_confirmed_to_cart(confirmed_items, access_token)`.
- Get `(cart_session, success_count, fail_count, error_msg)`.
- If fail_count > 0 and success_count > 0: render success with partial failure warning.
- If fail_count == len(confirmed_items): render full error.
- Otherwise: render success screen.
- Return `templates.TemplateResponse(request, "partials/success_screen.html", {"session": cart_session, "items": confirmed_items, "success_count": success_count, "fail_count": fail_count, "error_msg": error_msg})`.
