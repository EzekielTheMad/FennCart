**Endpoints to implement:**

**GET /settings** — Main settings page. Reads AppConfig from DB. Accepts optional query param `section` (default `"llm"`). Renders `pages/settings.html` with context: `active_page="settings"`, `active_section=section`, `cfg=appconfig_row`. The default section (LLM) is included inline via Jinja2 `{% include %}`.

**GET /settings/section/{section}** — HTMX partial for section switching. `section` is one of: `llm`, `store`, `account`, `preferences`. Reads AppConfig and renders the appropriate partial template. For each section:
- `llm`: render `partials/settings/llm.html` with `cfg` (AppConfig row) and `llm_cfg` (from `get_active_llm_config()`). The template needs to know the current provider, model, whether a DB key exists (`has_db_key = bool(cfg.llm_api_key_encrypted)`), and `ollama_base_url`.
- `store`: render `partials/settings/store.html` with `cfg` (for store_name, store_zip).
- `account`: render `partials/settings/account.html` with `is_authorized` boolean (check if OAuthToken exists and is not expired via `get_valid_access_token(session)`).
- `preferences`: render `partials/settings/preferences.html` with `cfg` (for review_mode).

Template context must always include `active_section` for sidebar highlight state.

**POST /settings/save-llm** — Save LLM provider config. Form fields: `provider` (str), `model` (str), `api_key` (str, may be empty), `custom_model` (str, may be empty), `ollama_base_url` (str, may be empty). Logic:
1. Determine active model: `custom_model if custom_model else model`
2. Determine active key: `api_key if provider != "ollama" else ""`
3. Determine base_url: `ollama_base_url if provider == "ollama" else None`
4. Call `llm_service.test_connection(api_key=active_key, provider=provider, model=active_model, base_url=base_url)` per D-08
5. If test fails: return `partials/settings/llm.html` with `error=message` context, do NOT save
6. If test succeeds: read AppConfig row, update `llm_provider`, `llm_model`. If `provider == "ollama"`, set `llm_api_key_encrypted = None` and `llm_ollama_base_url = ollama_base_url`. If cloud provider and `api_key` is not empty, encrypt with `get_or_create_fernet().encrypt(api_key.encode()).decode()` and store in `llm_api_key_encrypted`. If `api_key` is empty (user left blank to keep current), do NOT overwrite `llm_api_key_encrypted`. Commit.
7. Return `partials/settings/llm.html` with `success="Provider updated successfully."` context.

**POST /settings/search-stores** — Form field: `zip_code` (str). Calls `kroger_client.search_stores(zip_code, settings.kroger_client_id, settings.kroger_client_secret)`. Returns `partials/settings/store.html` with `stores` list, `zip_code`, and `cfg`. Do NOT modify `wizard_step` or `wizard_complete` (Pitfall 4 from RESEARCH).

**POST /settings/select-store** — Form fields: `store_id`, `store_name`, `store_zip`. Updates AppConfig `store_id`, `store_name`, `store_zip`. Commit. Returns `partials/settings/store.html` with `success="{store_name} saved."` and updated `cfg`.

**POST /settings/save-preferences** — Form field: `review_mode` (str, `"exceptions"` or `"full"`). Updates AppConfig `review_mode`. Commit. Returns `partials/settings/preferences.html` with `success="Preferences saved."`.

Helper function `_get_or_create_config(session)` to DRY the AppConfig read:
```python
async def _get_or_create_config(session: AsyncSession) -> AppConfig:
    result = await session.execute(select(AppConfig).where(AppConfig.id == 1))
    cfg = result.scalar_one_or_none()
    if cfg is None:
        cfg = AppConfig(id=1)
        session.add(cfg)
        await session.commit()
        await session.refresh(cfg)
    return cfg
```
