SESSION_SECRET_KEY not set

FennCart requires a unique secret key for session cookie signing. The default value is not allowed. Set SESSION_SECRET_KEY in your .env file or Docker environment and restart the container.

Generate a secure key:

python -c "import secrets; print(secrets.token_urlsafe(32))"

Then add it to your .env file:

SESSION_SECRET_KEY=your-generated-key-here

After setting the key, restart the container: docker compose restart
